# 五個台北立委選區的政黨優勢：探索分析

日期：2026-10-07。未改動頁面，未作選情預測。

## 範圍與方法

近期定義為2014–2024年的總統、市長及區域立委選舉，另匯出2012總統作前期參考。2023第3選區補選單列；2025罷免不是候選人選舉，不與兩黨候選人占比混算。市議員為複數席次制度，不適合拿單一候選人得票率直接比較這裡的單一席次勝負。

第3選區中山及北松山20里；第4內湖南港；第6大安；第7信義及南松山13里；第8文山及中正南側10里。按里加總票數/有效票，非平均里百分比。2012–2024資料中對應里數為62、59、53、54、53；松山里集合完整覆蓋且不重複，候選人票數守恆。相同里名不保證歷史邊界及選民群體完全固定。

總統/市長資料來自既有使用者提供的試算表快照及data/taipei-elections.json；不是本次完整逐里官方核驗。所有精確選區比例應視為探索結果，發布前需官方逐里原始票數復核。

分母始終是該場所有有效票。不把柯文哲、黃珊珊、宋楚瑜自動歸入藍綠，不將兩黨票重新正規化。2014沒有民進黨市長候選人；2016這五區沒有民進黨籍立委候選人，禮讓者仍按本來政黨列示。

## 發現

- 2014柯文哲在五區皆高於連勝文；不能把這些票稱為民進黨基本盤。
- 2016、2020總統，民進黨在3、4、6、7均領先國民黨，8則國民黨領先；2016第8兩人僅差約0.07百分點。
- 2020同日：蔡英文在大安48.89>韓46.97；立委林奕華52.41>謝佩芬42.32。第3及7也同日總統綠領先、立委藍勝。選舉類型的差異不可忽視；不是已識別個人分裂投票。
- 港湖李彥秀2020為47.44落選、2024為47.64當選。自己的占比僅差0.20百分點，勝負卻變。對手占比與競爭組合重要，不能據此推定整合後所有票可轉移。
- 大安立委國民黨換蔣乃辛→林奕華→羅智強仍勝，是較強的政黨/地方結構延續證據；不能估出任意候選人的勝率。文山南中正仍是五區中總統藍優勢較持續者，但立委賴士葆未換人，不能把其個人支持與政黨效果分離。
- 2016松信費鴻泰45.04對楊實秋42.28，差2.76百分點；2020費46.28對許43.00，差3.28百分點。不是一直有安全的大幅差距。
- 得票率是觀察結果，不是固定忠誠支持者的直接測量。沒有候選人品質及競爭對手的反事實，不能證明「派誰都贏」。政黨票應另補逐里資料，不能用行政區政黨票冒充拆分後立委選區。

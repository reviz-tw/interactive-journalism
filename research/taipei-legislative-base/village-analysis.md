# 四個立委選區，222里的跨選舉比較

研究日期：2026-10-08。分析而非頁面改版。涵蓋2014、2018、2022市長；2016、2020、2024總統與立委；第3選區另有2023補選。

來源：視覺化速查選舉資料庫（taiwanvotes.tw），整理自中央選舉委員會「選舉資料庫（含選舉區資料）」，來源版本2026-07-04+sha256:84740535b1f4，本站建置2026-09-14，本次擷取2026-10-08。這是網站整理版，未直接下載原始中選會壓縮檔。資料及授權：https://taiwanvotes.tw/download/ 。政府資料開放授權條款第1版 https://data.gov.tw/license；整理層CC BY4.0，署名視覺化速查選舉資料庫（taiwanvotes.tw）。變更：選取四個立委選區、計算有效票比例並跨年對照。原檔與版本清單保存在raw。

中山北松山62里、大安53里、信義南松山54里、文山南中正53里。合計222里。全體候選人得票相加作各場有效票分母，不把非藍票視為綠票。2014市長、2016四區立委沒有民進黨籍候選人，候選人按原黨籍呈現。2016立委潘建志、黃珊珊、范雲、楊實秋、李慶元等不能直接改標民進黨；2024苗博雅為社民黨籍。

輸出village-candidate-shares.csv：所有候選人長表、票數、各場有效票、得票率；village-comparison.csv：一里一列，各候選人跨選舉比例。空白是該選區/選舉沒有此候選人，不是0票。各年按里名對照，未證明里界及人口完全不變。

驗證：2060個里×選舉組合、12436筆候選人紀錄。每組號次唯一、票數守恆、比例合計100%；每場四區里數完整；立委資料選區代碼與地理範圍一致。2016/2020/2024四區國民黨候選人總票數及有效票與已查結果一致。四區總統/市長逐筆票數與既有使用者資料一致（信義富臺里/富台里僅明示名稱映射）；不宣稱對官方原檔已完成逐里核驗。

2020同日蔡英文最高票、國民黨立委最高票的里数依序32、35、21、23，合計111。這是里層級兩種選票結果，不能識別個人分裂投票。里數不按人口或票數加權，小里與大里各算1，不能把里數比例當成選民比例。

2016/2020/2024三屆立委都由國民黨候選人取得里內最高票，依序40/62、47/53、33/54、51/53。文山南中正最連續，但候選人三次皆賴士葆；大安三次不同候選人但47里皆藍最高，是政黨及地方結構延續的重要觀察。

仍須注意：取得最高票不代表過半或大幅領先。請同時看實際百分比與候選人差距。2024中山正守里王鴻薇48.81%、謝佩芬48.05%，不能把里內藍最高稱為碾壓。2024大安黎元里羅智強49.72%、苗博雅48.04%，也是接近的競爭。
